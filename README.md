# MASSA+ V2

E-book MASSA+ + primeira versão da área privada ligada ao Supabase.

## Publicação

O projeto funciona com as credenciais públicas configuradas em `src/supabase.ts`. A publishable key é apropriada para frontend quando o RLS está configurado.

Nunca coloque uma `sb_secret_...` ou `service_role` no frontend.
